# Kenney Particle Pack textures

These files are selected from [Kenney Particle Pack 1.1](https://kenney.nl/assets/particle-pack).
The pack's `License.txt` is included here; it licenses the textures under CC0.
Only six transparent 512×512 textures used by the waterfall are retained:
`circle_05.png`, `flame_06.png`, `light_01.png`, `smoke_03.png`,
`star_07.png`, and `trace_06.png`.
They are embedded in the local renderer bundle, so rendering does not fetch assets
from the network. The original author is Kenney Vleugels.
