# 和声音流与配器面板

当前用于普罗第二钢协的视频样片及完整版。播放中的两块面板均为纯展示，没有点击操作。完整版入口见[生成指南](prokofiev2-full-video.md)。

## 调整大小、颜色和生成样片

1. 双击根目录 **编辑视频字幕.bat**，点击左下角 **和声／配器面板设置**。
2. 分别调整和声瀑布图、配器面板的百分比，或选择和声类别／配器乐器修改颜色。默认100%，支持60%–150%；文字、音符与模块会等比例缩放。可单独关闭任一面板。
3. 点击 **保存并生成45秒样片**，完成后点击 **打开最近样片**。

默认选取原视频10:15起的全奏片段，包含乐队进入和打击乐。也可切换到01:31起的抒情片段。

可从命令行直接打开同一设置窗口：

```powershell
.\编辑视频字幕.bat --panels
```

保存后按现有设置直接生成：

```powershell
.\编辑视频字幕.bat --panels --render
```

设置位于本机 `local/video-export/prokofiev2-visual-panels.json`；位置由 `config/video-export.json` 统一指定。每次另存新样片，旧成片和其他项目的字幕文稿保留。

## 画面含义

- 每个原谱分部对应独立模块，按独奏、木管、铜管、打击乐、弦乐等分组。同类乐器合奏在原XML中未拆开时，维持一个分部，不猜演奏员分别何时起音。
- 起音时短暂亮起，持续时柔和高亮，停止后快速淡回暗色。延音线接续保持持续状态，不重复触发起音闪亮。动画不表示声学响度或踏板余响。
- **和声瀑布图只展示五类：钢琴、弦乐、木管、铜管、打击乐。** 同类音符使用相同颜色与轨道归类；原始乐器和音符身份保留在数据中。
- **配器激活面板继续逐件显示19个乐器模块**（含一、二小提琴组），不拆成钢琴左右手或复调声线。其颜色可以独立设置。
- 五类和声颜色、逐件配器颜色在设置窗口中分开列出。默认以字幕黄为中心，扩大到橙金、黄绿、青绿；用户自选颜色继续保留。
- 有明确音高的定音鼓进入音级列；非定音打击乐显示在右侧独立节奏列，各分部保留自己的细轨，不赋予虚构音级。
- 图形按原视频秒数从现有DTW映射取值；调整大小和颜色不改音符时间或已有字幕时间。当前样片没有新增文字字幕或PDF图层。

和声图默认400×240，顶部只有五类图例。配器面板默认520×280；两者仍可分别等比例调整。

分析文字当前尚未加入这段可视化样片。后续视频可以在下方共用分析区域展示和声、配器、复调、曲式的解释，并保留四类标签；上方两图只负责动态事实展示。

## 新作品的接入方式

组件读取乐器ID、显示名、分组、颜色和可选的独奏身份。和声分类由作品清单的 `harmony_groups` 显式指定，当前普二是上述五类；配器清单仍逐件保留。小提琴协奏曲可改用独奏小提琴分类；交响曲不必设置独奏模块；室内乐可另设适合自身编制的分类。不会把第一小提琴组自动当作独奏。

普二当前清单为 `works/prokofiev-piano-concerto-2/metadata/visual-parts.json`，与源XML指纹绑定。其他作品仍需接入自己的声部清单、音符活动和同场录音时间映射；不能只换乐器名称后套用普二的时间。
