# 普罗第二钢协：编辑并生成完整版

字幕、168页原PDF、同步高亮、和声五类及逐件配器图层已准备。本次只修订JSON、ASS与同步布局计划；既有用户成片保留，新视频由用户生成和核查。

处理新作品或重制旧视频，先阅读[完整技术路线](../workflows/video-remastering-playbook.md)。可直接复制的视频简介、章节和参考文献在[视频简介](../../works/prokofiev-piano-concerto-2/video-export/video-description.txt)。

## 直接使用

1. 双击根目录 **编辑视频字幕.bat**。
2. 选择 **普罗第二钢协 · 王羽佳／雅尔维完整版**。当前默认已选此项目。
3. 在“文字与出现时间”编辑字幕；在“位置、字体与滚动”调整文字样式。完成后点击 **保存并生成新视频**。
4. 生成结束后点击 **打开最新视频**。每次都会另存到新的 `edits-XXX` 目录，已有成片保留。

可编辑字幕为 `works/prokofiev-piano-concerto-2/video-export/captions-editable.json`，当前共218条：和声39、配器41、声部关系与复调42、曲式与主题发展42、导聆41、诠释12、片头1。原200条保留，新增18条填充讨论过的十段长空白；出处、谱面入口与排布结果在同目录`gap-fill-plan.json`及`gap-fill-evidence.json`。完整研究文章仍在网页。

需要调整动态图形大小和颜色时，在批处理项目选择页点击 **和声／配器面板设置**，保存后再到完整版项目生成。图形整体大小会带动下方文字区和右侧PDF的默认位置重新避让；单条字幕的自定义位置仍以自己的设置为准。设置页的45秒片段选择只影响样片，不改变完整版范围。

## 当前范围和版式

- 原视频0:00–32:28.20，包含四个乐章及其真实停顿，末章结束后留4秒；不包含后段加演。
- 上方：和声瀑布图按钢琴、弦乐、木管、铜管、打击乐五类显示；配器激活面板逐件显示19个模块。
- 右侧：PDF显示区为x=1320、宽600；纸张本身向右对齐，紧贴1920画面右侧。共用华彩区域采用整段高亮，关闭虚构的页内播放线。
- 四类分析：两列各600像素宽，列间24像素；每区168像素高，行间8像素。默认标题起点y=320、496；导聆移至y=672，高168像素，当前41段均能完整显示而无需滚动。
- 分析读完退场：按每秒5字、读后留3秒、最少10秒计算显示时间，随后整体渐隐。原JSON里的音乐段落起止不改；华彩不会一直挂着同一段短分析。相邻不变的文字不重置阅读计时。
- 十二段诠释：原九段加三段接续长文，约半分钟到五十秒；44号楷体，在x=220、y=336、1480×720的平面矩形内整体缓升约75像素，末4秒整体渐隐。出现时暂时隐藏四类分析、导聆和PDF，上方双图层继续同步；结束后PDF恢复到当前正确位置，不补播已过阅读期的旧分析。
- 片头在40.2秒清空，43.2秒进入本曲同步；乐章停顿、谢幕期间不显示虚构的音符与谱面高亮。

文字继续采用黄色楷体。短文案保持静止；普通长文只滚动真实溢出的行数，以每秒26像素乘滚动倍速计算，末行完整进入即停，保留完整末段，禁止继续滚空。孤短末行会与上一行重新平衡，意大利文单词优先完整换行。诠释为独立的宽幅缓升模式，所有正文行一起移动，不逐行滚出画面。

`captions-editable.json`的“呈现规则”可调整阅读时间、淡入淡出、普通滚动像素速度、诠释上移距离和临时隐藏对象；“字幕样式”继续调整位置、字号及倍速。高于24秒的长文会保留足够阅读时间，不强行套用短文时长上限。改完JSON后请重新打开编辑器，避免已打开的旧窗口覆盖新稿。

## 文件与核查

导出包位于 `output/video-export/prokofiev2-full-001/`，只留本机。它包含原视频工作副本、谱页缓存、同步计划、原始帧时间戳和可视化数据。生成时复用这些结果，不重算DTW或识谱，也不上传材料。

十段补充后的最新预备结果是`edits-006/analysis.ass`及`score-plan.json`，`gap-fill-check.json`记录覆盖、阅读、同步计划和媒体保留检查。本次没有生成视频或新版合成静帧。`edits-004`是前一轮排版预备结果；`edits-002/preview-*.png`为早期版式。用户的`edits-003`及`edits-005`成片保留。

十段补充按已有XML小节入口进入，每段音乐部分新增文字覆盖约41%–65%，其余留给听音乐；原十段内最长音乐空白降为18.97秒。整个曲目的文字空白由59.11%降为41.98%，全曲仍有未在本轮处理的45.56秒空白。补充不会自动扩展到其他段落，也不会填入乐章间停顿。详见[补写与调度报告](../../reports/prokofiev2-gap-fill-20261027.md)。

原视频约30fps，保留原片呈现时间与AAC音轨；动态图形按实际帧时间取值，处理源文件毫秒级时间戳差异。底层同步仍为原有候选映射，特别留意自由速度、华彩、乐章首尾和已知XML异常处。

命令行可直接使用同一编辑入口：

```powershell
.\编辑视频字幕.bat --project prokofiev2-full
.\编辑视频字幕.bat --project prokofiev2-full --render
```

只有自己选择生成后才编码视频。“保存修改”只保存JSON，“仅导出ASS”只生成字幕文件。
