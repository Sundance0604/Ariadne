# 马勒第四：原谱高亮、分析稿与一键启动

日期：2026-10-25。根据用户后续指令，取消动态尺寸调整，保留原有布局和缩放控制。本轮实现自动候选高亮、导聆文稿与文献接入，并新增 Windows 一键启动。

## 自动高亮数据

原 PDF 共 127 页，其中物理第 5–127 页为乐谱。图像谱线、贯穿条线与音符头检测得到 172 个系统，覆盖这 123 个乐谱页。四乐章分别包含 65、36、38、33 个系统。矩形均来自原谱图像，不按页数或时长均分。

实查发现辅助 MIDI 每乐章的拍号固定，候选分节不等于原谱小节。定位因此使用原图底部多个谱表的音级轮廓、MIDI 联合弦乐音符和可变时值匹配；原谱页／区域独立于 1,244 个 MIDI 参考段。算法以全乐章参考总时值为边界约束，局部拍号长度来自推断，尚未全部从图像直接读出。谱号、临时变音、长休止、漏检条线及参考版本差异均可能影响结果。

两组音符阈值和两种时值先验用于对照。172 个系统中，108 个满足本轮稳定规则（音级直方图相似度至少 0.5、几种参数的边界分歧不超过 5 秒参考时间）；64 个标为 `needs_review`。在更严格的局部规则下，另有 384 个小节矩形细分候选（相似度至少 0.65、分歧不超过 1 秒、有至少两个音符簇）。这些数字表示候选与参数稳定性，**不表示准确率，也不表示任何小节已由人工确认**。

独立 STFT 音级诊断另检查了音轨—MIDI 路径，26 个参考段音高支持较弱，27 个没有足够音高参考；它们不等于谱面几何错误，也不替代试听。原全曲对齐仍为自动候选。

数据在 `works/mahler-4/measure-map.json`，诊断在 `works/mahler-4/reports/score-region-validation.json`。原谱矩形叠加样张在同目录 `score-region-overlays.png`：绿色为较严格的小节候选、橙色为系统候选、红色为待复核系统。已经查看第 5、6、49、78、102、127 页叠加图，矩形落在实际谱表／小节线范围内；该视觉检查不能证明录音时间边界精确。

## 播放行为与人工修正

视频当前时间驱动独立原谱区域，较细的小节候选优先；没有可用细分时回到所在系统。自动翻页、当前系统进入可见范围、点击谱面跳转与原有播放线共用同一时钟。播放线仍是区域内的估计进度，不宣称精确拍点或逐音符位置。

匹配分歧或音轨诊断疑点使用红框和状态提示；“仅显示稳定候选”可隐藏不稳定谱面窗口，空缺不外推。全部候选仍保留复核状态，不伪装成印刷小节编号。

“同步信息与人工校正”新增区域起止秒数、以当前播放设起止、核验依据和确认勾选。保存绑定当前曲目、PDF 与视频指纹，保留旧值／新值及修改历史，写入独立的 `score-region-anchors.json`，立即生效。不同素材、非有限时间、错误顺序及不相关人工区域的时间冲突会被拒绝。测试仅在隔离夹具中保存，未制造真实项目的人工验收记录。

## 一键启动

根目录 `启动播放器.bat` 自动进入本目录，优先使用 `.venv`；缺少时使用本机 Python 3.11+ 创建环境，缺少播放依赖时安装 `requirements.txt`。默认打开马勒第四；`/api/health` 校验项目身份，复用本项目已有服务，避免重复实例，也不会误用其他目录的服务。端口占用时尝试 8765–8785 中其他本地端口。

已实际通过 `cmd` 执行 BAT 的启动检查模式，确认工作目录、中文路径、环境识别及已有实例复用；端口占用回退及跨目录拒绝复用也有测试。当前环境已有播放依赖，因此首次自动安装分支没有实际触发。只监听 `127.0.0.1`，不上传媒体。

## 复现

播放：双击 `启动播放器.bat`，或 `python start.py`。

重建图像定位需处理依赖：`python scripts/map_mahler4_pdf.py`。缓存绑定 PDF 与四个 MIDI 指纹；输出保留原始观测、参数对照与待复核状态。重新导入修订稿：`python scripts/import_mahler4_analysis.py`。独立音高诊断：`python scripts/validate_mahler4_sync.py`。

音轨重算继续使用 `scripts/align_recording.py`。已有文稿、谱面矩形和人工校正不应被初始占位数据覆盖；本轮已更新 `build_mahler4_video.py` 的保留逻辑。
