## 结论

**MIDI 辅助的离线全曲对齐测试已经跑通，并生成可在原始 PDF 上检查的候选同步结果。** 主计算覆盖整首录音，输出 535 个候选小节和 53 个 MIDI marker 的录音位置。当前有 33 个重点复核小节、502 个其余未复核小节，人工确认数为 0。

这不是“全曲已准确同步”的人工验收结论。没有完成全谱 PDF → OMR → 不提供用户 MIDI 的全曲对齐，不能用本次 MIDI 路径代替该项验收。四页 OMR 小样已经运行，但结果仍有识谱疑点。

## 对齐方法与可追溯数据

1. 用 soundfile 完整解码本地 MP3，合并双声道进行特征提取，重采样为 22,050 Hz。
2. 在全曲分散选取的八段音频上估计调律，得到 +12 cents；该值是算法估计，未当作乐团真实调律的已确认事实。
3. 提取全曲量化 chroma 和 DLNCO onset 特征，50 帧/秒；参考侧由原始 MIDI 音符时段与 onset 生成符号特征。
4. 调用 Sync Toolbox MrMsDTW，步进权重 `[1.5, 1.5, 2.0]`，区域阈值 `10^6`，不使用全曲时长比例代替对齐。
5. 另跑一次 chroma-only 对齐，记录两者在小节起点处的分歧。
6. 将 MIDI 变拍号边界投影到 DTW 路径。对一个谱面帧对应的多音频帧取中位数，原始路径另存为 `alignment.path.npz`，不掩盖原路径的水平/垂直段。

全曲路径包含 57,551 个点，单调，覆盖两条特征序列端点；音频与参考特征形状分别为 `12 × 54,801` 和 `12 × 52,329`。所有候选小节的时间严格递增、时段为正、相邻小节衔接且不超出录音时长。这些是结构检查，不能独立证明音乐位置正确。

`alignment.json` 明确标识 `source_type: user_midi_auxiliary`、`pdf_omr_used: false`。没有把 MIDI 推导的小节 ID 宣传成来自已复核 MusicXML 的小节 ID。

## MIDI 输入异常

原始 26,141 个非零力度 note-on 中形成 24,133 个正时长音符，另有 2,008 个零时长事件；主要集中于定音鼓轨（1,706 个），钢琴主轨也有 183 个。还有 653 个未配对的结束事件，没有发现悬而未闭的 note-on。逐项记录在 `reports/midi-parse.json`。

最初 pretty_midi 发出了非零轨元事件警告；复查发现本文件速度与拍号事件都在轨 0，其他轨还有调号。为明确事件处理，实际对齐用 mido 按轨道、MIDI port、通道和音高配对，并记录而非隐藏异常。正时长音符总数与 pretty_midi 相同，不能把差额解释为某个库漏读全部这些音符。

特征侧排除无音高打击乐通道，保留 21–108 范围内的 22,905 个有音高音符时段。零时长音符没有被任意补成长音；延音踏板和 pitch bend 尚未建模。这些限制尤其需要在华彩和复杂打击乐段检查。

## 原始 PDF 显示与坐标

本次校验页显示的是用户提供的 **100 页 MuseScore 重排 PDF 的原始页面**，没有用重新排版的 MusicXML 替换它。其原始指纹保存在 `measure-map.json` 和 `project.json`。

从矢量谱线、小节线和谱表组开头的印刷编号提取出 162 个系统，535 个候选 ID 全部有区域、没有重复 ID。提取器会排除延长到小节线之后的提示性谱号/调号空白，避免把它们识为新小节；这些问题在早期几何检查中被发现并修复。

- 第 89、98 页的部分原始矢量线延伸到页面下边界之外约几 pt。高亮框裁至页面范围，保留未裁矩形并为候选小节 476–477、527–528 加标记；未据此断言音符一定损坏。
- 99 页扫描谱的坐标与重排版不共用。扫描版目前用于抽样核对与 OMR，不在校验页中冒用重排坐标。

## 独立证据与重点复核

除了对齐本身的特征对照，又从录音单独提取了 STFT chroma（11,025 Hz，FFT 4096，hop 1102），与映射处的符号音高类别比较。有效诊断样本 4,134 个，排除缺少有音高参考的 49 个样本。

对齐位置的余弦相似度中位数约 0.765；把音频位置错移 −8、+8、−16、+16 秒时，对照中位数约为 0.440、0.464、0.403、0.416。这支持映射在整体上比这些错移对照更合理，**不是 76.5% 正确率，也不能排除相似和声、反复或局部错位**。

重点复核共 33 个小节，完整清单见 `reports/alignment-anomalies.csv`。标记可重叠：

| 依据 | 数量 | 含义 |
| --- | ---: | --- |
| 独立音高证据偏弱 | 21 | 余弦相似度中位数 < 0.5 的工程筛查阈值，未经准确率校准 |
| 两种对齐特征分歧 > 2 秒 | 3 | 候选小节 36、39、535；建议试听起点，不能直接选其中一组为真值 |
| 华彩共用谱面区域 | 4 | 候选小节 33–36；缺少独立可见小节边界 |
| 录音边缘 | 4 | 候选小节 1、2、3、535；弱开头与结尾混响尤其难仅凭全局端点判断 |
| 有音高参考不足 | 1 | 无法用当前音高诊断判断候选小节 280 的同步 |
| 原始几何超出页边界 | 4 | 候选小节 476、477、527、528 |
| MIDI 末小节不足完整名义时值 | 1 | 文件在最后 note-off 后结束，标记复核，不直接认定记谱错误 |

所有其他小节仍是 `unreviewed`，没有因“未触发阈值”而自动变成 `verified`。人可以在校验页试听、看谱、保存锚点；修改保留原值、新值、依据与时间，重新计算不会静默覆盖已有人工确认文件。
