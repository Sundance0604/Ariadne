# 《云雀高飞》合并与校对

日期：2026-10-25。

## 集成结果

已接入同一个本地播放器。顶部曲目选择分别读取拉威尔根目录和 `works/lark-ascending/`，音频、谱面、小节候选、录音资料、导聆与文献使用同一曲目白名单。新作包含 35 页总谱、309 个 MIDI 候选分节、35 段导聆及 8 项参考资料。录音标签对应 Hilary Hahn / Sir Colin Davis / London Symphony Orchestra，实际解码时长约 16 分 18 秒。

本版谱面数字与 MIDI 候选序号存在差异，不能直接对应。当前坐标候选有 216 个常规小节区域、63 个华彩区域关联、30 个系统或乐句区域关联；共用区域不绘制不存在的小节线，也不冒称逐音符进度。分段不同与共用区域的复核理由已用中文显示。独立诊断完成后，98 个候选标为重点复核，其余 211 个仍未人工确认，没有任何候选标为已人工通过。以上区域数量是定位方式的分类，不是精度或人工通过率。

35 页导聆已导出到 `analysis/annotations.json`；播放时的正文仍从原 Markdown 动态读取。文献类型由曲目资料指定，避免把拉威尔的文献编号含义套入新作。原稿备份、谱面和学术核查范围详见 `analysis-editorial-review.md`。

## 隔离与保护

- 曲目查询只接受 `library.json` 中的明确标识，不能将查询值作为文件路径。
- 每首作品单独保存人工锚点；新界面提交时验证曲目标识、音频及 MIDI 指纹，并保护既有不匹配的锚点文件。
- 切换曲目会暂停并重新载入音频，清空旧谱面与导聆；较晚返回的旧请求不能覆盖新曲目。页面内尚未保存的锚点按曲目暂存，素材指纹改变后不会复用。
- 拉威尔 `alignment.json`、`measure-map.json`、`metadata/recording.json` 与本轮开始时的 SHA256 基线一致。父任务另以 `final-input-integrity.json` 核对新作原始 MP3/PDF/MIDI 未改、分析原稿备份与初始指纹一致。没有向真实曲目写入测试锚点。

## 实际验证

18 项自动测试中 16 项通过，2 项 M4A 实验按用户要求跳过。覆盖两曲数据绑定、35 页导聆覆盖、候选 ID 与谱面关联、文献类型配置、曲目目录边界、音频分段读取及人工锚点隔离；锚点写入测试只使用专用临时样本。`app.mjs` 和 `analysis.mjs` 的 JavaScript 语法检查通过。

对当前 8765 服务实际请求两首曲目的项目与导聆接口，核对各自音频/PDF 文件 SHA256；首、末页图片均能返回，超过各自页数的请求返回 404，音频分段读取内容与原文件一致。完整结果见 `integration-http.json`。

应用设置禁止本轮本地浏览器操作，因此没有完成真实浏览器中的曲目切换、控件播放、暂停/变速和播放线视觉验收。接口与语法通过不能替代上述验收，更不能替代全曲人工听辨；自动对齐和所有谱面坐标仍保留候选状态。

M4A 继续悬置，本轮仅使用用户提供的 MP3。
