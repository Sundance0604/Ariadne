# 《云雀高飞》全曲候选同步与谱面定位

处理日期：2026-10-25。所有音频、MIDI 和 PDF 留在本地。现有拉威尔曲目数据没有作为新曲输出覆盖。

## 输入与实际计算

- 录音：文件名所示 Hilary Hahn / London Symphony Orchestra / Sir Colin Davis，MP3。实际解码 43,125,096 帧、44,100 Hz、双声道，即 **977.893333 秒（16:17.893）**。Mutagen 等 MP3 元数据估计可能相差约 0.027 秒，以解码样本数为准。
- MIDI：12 轨、6819 个有效音符区间、130 个速度事件，参考时长 770.355398 秒；根据实际拍号与事件得到 **309 个候选时间区间**。原文件存在零时值音符、未配对 note-off 等解析异常，完整记录在 `midi-parse.json`；这些未被伪造修复。
- PDF：35 页 Godderis 署名矢量版本，提取 53 个系统。它与管弦乐录音的编制及排版不保证完全相同，不能据此断言逐音符相同版本。
- Sync Toolbox 1.4.2 的 MrMsDTW，50 Hz，量化 chroma + DLNCO；同时运行 chroma-only 对照。全曲提取与两次计算用时约 **54.95 秒**。没有按固定 BPM 或录音总时长等分区间。
- 原始 DTW 单调、覆盖完整特征两端，路径独立保存在 `alignment.path.npz`。强制端点本身不是准确性证据，开头与尾声另有复核标记。

## PDF 与 MIDI 编号的实质差异

MIDI 候选编号不能直接充当 PDF 印刷小节号。华彩段在本版 PDF 中大量省略小节线，辅助 MIDI 又对自由段进行不同分割。

本次从独奏谱表抽取音头纵坐标，以自然音级轮廓进行全序列候选匹配；使用 1843 个 PDF 音头与 2133 个 MIDI 独奏音符，得到 1743 对候选对应，其中 1702 对音级与八度相同、1734 对字母音级相同。匹配忽略临时升降号，八度记号采用小惩罚，连线与重复音也可能造成局部歧义；这些计数**不是准确率**。完整算法与对应保存在 `pdf-note-correspondence.json`。

在有可见小节线的常规段，多数音头对应支持下列编号关系，并与明确的拍号入口交叉检查：

| PDF 印刷范围 | MIDI 候选范围 | 关系与处理 |
| --- | --- | --- |
| 30–90 | 34–94 | 常规段偏移 +4；保留各实际小节矩形 |
| 100–207 | 107–214 | 常规段偏移 +7；第 12 页独奏直到最后才进入，因此不把独奏首音当作该页起点 |
| 208–228，PDF 27–28 页 | 215–239 | MIDI 产生额外分割，采用系统共用矩形；两页之间仍为轮廓导出的候选边界，需人工校准 |
| 229–273 | 240–284 | 常规段偏移 +11；第 29 页未印独奏谱表，依据前后有小节线段落计数关联 |
| 开头、中央与末尾华彩 | 其余候选 | 按谱页/系统与独奏音型候选关系共用区域；不虚构等宽小节线 |

总计 **216 个候选关联单个实际小节矩形**；**63 个候选共用华彩区域**；**30 个候选共用系统区域**。合计 309 个候选覆盖 35 页。所有关联仍是候选：有图像和轮廓支撑也不等于已逐音核验。开头两小节分离，第一页余下自由华彩作为共用区域；第 34 页下部包含独奏进入与乐队尾音，保留系统范围而不误标成完全无伴奏的纯华彩。

## 独立音频诊断与试听依据

另外使用 11,025 Hz 音频的 4096 点 STFT、1102 样本 hop，提取独立于对齐特征的 chroma，与映射后的 MIDI 音级作对照；每 0.25 秒参考时间取样，并与录音时间偏移 ±8、±16 秒的四个对照比较。

- 全曲有效样本 3051 个；对齐后余弦中位数 **0.8203**，四个偏移对照中位数约 **0.4370–0.4905**。
- 对齐点优于全部四个偏移对照的比例 **0.6001**；开头约 0.5970、中段约 0.5604、结尾约 0.6277。中段的重复和声与音型可能令多个时间点都相似。
- 开头、中段、结尾的对齐余弦中位数分别约 **0.8522、0.7906、0.8681**。
- 这些指标支持整体音乐材料存在对应，但不能证明没有局部跳转、精确音头误差或谱本细节差异；没有人工真值，不发布所谓同步准确率。

生成三个本地双声道试听片段：左声道为归一化录音，右声道为按非线性映射重定时的简化正弦参考。它们分别位于录音 0–55 秒、455–490 秒和 930–977.893 秒，对应 `output/review-opening.wav`、`review-middle.wav`、`review-ending.wav`。这些文件用于后续听辨，**本轮未声称已经人工听完验收**。诊断图见 `output/alignment-diagnostics.png`。

## 复现

使用 Conda `synctoolbox` 环境运行 `scripts/align_recording.py`，显式指定本曲 `--audio`、`--midi` 与 `--output works/lark-ascending/alignment.json`；该命令的无参数默认仍明确指向拉威尔目录。

PDF 运行时依次运行 `scripts/probe_lark_notes.py`、Conda 运行 `scripts/align_lark_pdf_notes.py`、PDF 运行时运行 `scripts/map_lark_pdf.py`；再由 Conda 运行 `scripts/validate_lark_alignment.py` 和 `scripts/build_lark_project.py`。报告、路径和试听均隔离于本曲目录。对齐重新计算后需重新运行定位与验证，避免丢失后加的复核标记。
